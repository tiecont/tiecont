## 👨‍💻 About Me

I'm a backend engineer focused on building reliable and maintainable production systems.

My recent work has involved:

* Designing and maintaining **REST APIs** and backend business workflows
* Building services with **TypeScript, Node.js and NestJS**
* Working with **PostgreSQL, Redis and relational data models**
* Authentication and authorization with **SSO, RBAC and permission systems**
* Reliable **background jobs, schedulers and retry/recovery workflows**
* **Distributed locking**, concurrency control and idempotent processing
* Email and notification delivery pipelines
* Database migrations and production data safety
* Unit, integration and **PostgreSQL-backed E2E testing**
* Docker-based development and testing environments
* Performance, memory usage and production failure recovery

I'm also exploring backend development with **Go** and contributing more to open source.
